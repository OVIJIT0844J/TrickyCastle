📐 Dungeon Escape Theory & Game State FSM

Designed the core puzzle-platformer gameplay theory inspired by Tricky Castle. Engineered a deterministic 14-state Finite State Machine (enum GameState) handling seamless transitions between Intro, Menus, In-game Play, Penalty Derby, and Level Clears.

  • •
    60 FPS Fixed Time-Step: Updates physics at ~16.6ms intervals using iSetTimer(16, updateGame).
  • •
    Parabolic Trajectory Equations: Height computed via y(t) = y₀ + vᵧ·t - ½·g·t² with dynamic variable jump apex.
  • •
    Dual Gravity Tensor: Supports normal gravity (+g downward) and inverted gravitational polarity for ceiling puzzles (-g upward).
  • •
    Axis-Aligned Bounding Box (AABB): Fast 2D geometric intersection tests against solid castle blocks and moving platforms.
GameLogic.h — Physics & Solid Tile Collision C++ / iGraphics 
// Fixed Euler Integration with Inverted Gravity Support
void updatePlayerPhysics() {
    if (!onGround) {
        if (!gravityInverted) {
            velocityY -= GRAVITY; // -0.52 standard gravity
            if (velocityY < -TERMINAL_VELOCITY) velocityY = -TERMINAL_VELOCITY;
        } else {
            velocityY += GRAVITY; // Inverted ceiling walk
            if (velocityY > TERMINAL_VELOCITY) velocityY = TERMINAL_VELOCITY;
        }
    }
    playerX += velocityX;
    playerY += velocityY;

    // Ground & Solid Platform Collision Detection
    for (int i = 0; i < platformCount; i++) {
        if (checkAABBCollision(playerX, playerY, PLAYER_WIDTH, PLAYER_HEIGHT,
                               platforms[i].x, platforms[i].y, platforms[i].w, platforms[i].h)) {
            resolvePlatformContact(i);
        }
    }
}

✨ Procedural Animation Without Bloated Sprite Sheets

Instead of loading hundreds of static PNG frames, engineered an organic procedural rendering pipeline (drawCharacterGraphics) using real-time mathematical trigonometric transforms:

  • •
    Idle Breathing Sway: Computes smooth subtle chest expansion using sin(levelTimer * 0.045) * 0.028 to bring stationary heroes alive.
  • •
    Articulated Run Stride: Calculates harmonic vertical bobbing bobY = |sin(walkCycle * 0.20)| * 4.0 synchronized with audio step triggers.
  • •
    Parabolic Squash & Stretch: Stretches character vertically on jump apex (scaleX=0.90, scaleY=1.12) and squashes on landing impact (scaleX=1.18, scaleY=0.82).
  • •
    Dynamic Facing Flip: Flips horizontal texture orientation instantly when changing directions without texture artifacts.

void playBgm(const char* filePath) {
    if (!bgmEnabled) return;
    mciSendString("close bgm", NULL, 0, NULL);

// Headless Automated Diagnostic Exporter
void saveGlScreenshot(const char* filename) {
    unsigned char* pixels = new unsigned char[SCREEN_WIDTH * SCREEN_HEIGHT * 3];
    glReadPixels(0, 0, SCREEN_WIDTH, SCREEN_HEIGHT, GL_RGB, GL_UNSIGNED_BYTE, pixels);
    
    // Encode BMP Header & Write Frame Buffer
    FILE* fp = fopen(filename, "wb");
    writeBmpHeader(fp, SCREEN_WIDTH, SCREEN_HEIGHT);
    fwrite(pixels, 1, SCREEN_WIDTH * SCREEN_HEIGHT * 3, fp);
    fclose(fp);
    delete[] pixels;
}
