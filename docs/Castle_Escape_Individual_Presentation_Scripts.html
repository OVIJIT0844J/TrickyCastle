🎓 Ovijit Sharma — Technical Defense Q&A Preparation
Q: Why did you choose fixed Euler Integration over Verlet or Runge-Kutta in GameLogic.h?
A: In a discrete 60 FPS grid-based platformer, fixed-step Euler integration provides guaranteed determinism, low computational complexity, and instantaneous velocity dampening upon collision contact. Since timestep dt is clamped to ~16.6ms by iSetTimer, Euler integration exhibits no observable drift for 2D platforming.
Q: How does drawGlowingText() work without native shader support in iGraphics?
A: We emulate bloom by executing multiple concentric rendering passes of the string. Each outer pass is offset radially by delta-r with alpha attenuated quadratically, using OpenGL alpha blending (glEnable(GL_BLEND); glBlendFunc(GL_SRC_ALPHA, GL_ONE_MINUS_SRC_ALPHA)).

🎓 Shahriar Rythm — Technical Defense Q&A Preparation
Q: How do you prevent memory leaks when loading and reloading 24 different levels in Levels.h?
A: All room entity collections (buttons, spikes, platforms) use fixed static arrays sized to maximum entity bounds (MAX_PLATFORMS, MAX_PROPS). loadLevel() re-initializes entity counts and properties in-place without dynamic malloc/free calls, completely eliminating heap fragmentation.
Q: How does the 3D red button determine if a player or crate is standing on it?
A: The button entity defines an active trigger AABB zone. During updateWorldObjects(), we check if the player's foot bounding box or any crate's bottom edge intersects the trigger zone. If true, button.depressed is set to true and y-offset shifts by 8 pixels downward.

🎓 Nabeel Saad Borno — Technical Defense Q&A Preparation
Q: How do you achieve the 3D depth effect in the World Select carousel without a 3D perspective matrix?
A: We use pseudo-3D trigonometric depth projection. Cards are positioned along an elliptical arc (x = cx + r*sin(theta)). The scale factor is computed as s = 0.82 + 0.18*cos(theta), and alpha opacity is modulated as a = 0.65 + 0.35*cos(theta), sorting rendering order by depth.
Q: How do toast notifications operate asynchronously without blocking iGraphics execution?
A: We store toast state in a struct (message, frameCount, alpha). In updateGame(), frameCount increments every tick. The render loop evaluates alpha = clamp(sin(pi * frame / 120), 0.0, 1.0) and draws the toast over the scene without halting game flow.

🎓 Maheed Abrar — Technical Defense Q&A Preparation
Q: Why did you write raw binary structs instead of JSON/XML in SaveSystem.h?
A: In C/C++ without external third-party parsing dependencies, fwrite and fread of a fixed-layout POD struct execute in sub-millisecond time (atomic disk write). It eliminates string parsing overhead and protects against save-file tampering.
Q: How does the 3D ball projectile achieve perspective depth in PenaltyGame.h?
A: The ball calculates an interpolation factor t from 0.0 (penalty spot) to 1.0 (goal line). Current radius is linearly interpolated: r(t) = 24.0 * (1.0 - t) + 9.0 * t. Vertical position follows a quadratic trajectory y(t) = y0 + vy*t - 0.5*g*t^2, providing convincing 3D flight.
